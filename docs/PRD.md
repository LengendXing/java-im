# Java IM 产品需求文档 (PRD)

## 1. 项目概述

**项目名称：** java-im
**版本：** v0.1.0
**定位：** 从零到一构建的即时通讯系统，基于 Java Vert.x 服务端 + 多端客户端（PC/Android/Web）
**核心目标：** 实现一个功能完整、架构清晰、可水平扩展的 IM 系统

## 2. 功能需求

### 2.1 用户体系

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 用户注册 | 手机号/用户名注册，密码加盐哈希存储 | P0 |
| 用户登录 | Token 签发，多端登录控制（最多3端同时在线） | P0 |
| 用户登出 | Token 失效，连接断开 | P0 |
| 个人资料 | 昵称、头像、签名、在线状态 | P1 |
| 多端同步 | 同一账号多设备消息同步 | P1 |

### 2.2 消息功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 单聊(C2C) | 一对一文字/图片/文件消息 | P0 |
| 群聊(C2G) | 群组消息，支持@成员 | P0 |
| 消息已读 | 已读/未读状态，未读计数 | P1 |
| 消息撤回 | 2分钟内可撤回 | P1 |
| 离线消息 | 用户上线后自动拉取离线消息 | P0 |
| 历史消息 | 按会话分页拉取历史记录（消息漫游） | P0 |
| 消息通知 | 在线推送 + 离线推送（APNs/FCM） | P1 |

### 2.3 会话管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 会话列表 | 按最新消息排序的会话列表 | P0 |
| 未读计数 | 每个会话的未读消息数 + 全局未读总数 | P0 |
| 会话删除 | 删除会话（仅本地，不影响对方） | P2 |
| 置顶/免打扰 | 会话置顶、消息免打扰 | P2 |

### 2.4 关系链

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 好友申请 | 发送/接受/拒绝好友申请 | P0 |
| 好友列表 | 好友列表查询 | P0 |
| 好友删除 | 删除好友，双向解除关系 | P1 |
| 黑名单 | 拉黑/解除黑名单 | P2 |

### 2.5 群组功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建群组 | 创建群聊，设置群名/公告 | P0 |
| 邀请入群 | 群主/管理员邀请成员 | P0 |
| 踢出群组 | 群主/管理员踢出成员 | P1 |
| 退出群组 | 普通成员主动退群 | P0 |
| 解散群组 | 群主解散群 | P1 |
| 群成员列表 | 查询群内成员 | P0 |
| 群资料修改 | 群名、群公告、群头像 | P2 |

### 2.6 消息类型

| 类型 | 描述 | 优先级 |
|------|------|--------|
| 文本消息 | 纯文本内容 | P0 |
| 图片消息 | 图片 URL + 缩略图 + 尺寸 | P0 |
| 文件消息 | 文件 URL + 文件名 + 大小 | P1 |
| 语音消息 | 语音文件 URL + 时长 | P2 |
| 系统消息 | 好友申请/群变更等系统通知 | P0 |

## 3. 非功能需求

### 3.1 性能

- 单节点支撑 10 万长连接
- 消息延迟 < 200ms（同机房）
- 消息吞吐 > 1万 TPS/节点

### 3.2 可用性

- 服务无单点故障
- 支持水平扩展（Gateway/Logic 层无状态）
- 消息不丢失（持久化 + ACK 确认机制）

### 3.3 安全性

- TLS 传输加密
- Token 认证（JWT）
- 消息内容 AES-256 端到端加密（v0.2+）
- 防重放攻击（sequenceId 去重）

### 3.4 可运维性

- Prometheus + Grafana 监控
- ELK 日志聚合
- Docker 容器化部署
- 健康检查接口

## 4. 客户端平台

| 平台 | 技术栈 | 传输协议 |
|------|--------|---------|
| PC (桌面) | JavaFX / Electron | TCP + Protobuf |
| Android | Kotlin + Jetpack Compose | TCP + Protobuf |
| Web | Vue 3 + TypeScript | WebSocket + JSON/Protobuf |

## 5. 服务端技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| 核心框架 | Vert.x 4.x | 异步非阻塞，EventBus，多语言支持 |
| 网络层 | Vert.x TCP/WebSocket | 长连接接入 |
| 协议 | Protobuf v3 | 二进制序列化，跨语言 |
| 消息中间件 | Kafka/RocketMQ | 推送削峰、异步解耦 |
| 缓存 | Redis | 在线状态、路由表、未读计数、会话缓存 |
| 数据库 | MySQL + TiDB | 关系数据 + 海量消息存储 |
| 对象存储 | MinIO | 文件/图片/语音存储 |
| 注册发现 | Nacos | 服务注册与发现 |
| 监控 | Prometheus + Grafana | 指标采集与可视化 |
| 容器 | Docker + Docker Compose | 开发环境一键部署 |

## 6. 里程碑规划

### Phase 1 — v0.1.0 核心通讯（当前）

- 用户注册/登录/登出
- 单聊文字消息
- 群聊文字消息
- 离线消息拉取
- 会话列表 + 未读计数
- Protobuf 协议定义
- Vert.x 服务端骨架

### Phase 2 — v0.2.0 多媒体 & 关系链

- 图片/文件消息
- 好友系统
- 群组管理完善
- 消息已读/撤回
- 端到端加密

### Phase 3 — v0.3.0 高可用 & 运维

- 分布式部署
- 消息中间件集成
- 监控告警
- 压力测试
- Android 客户端

### Phase 4 — v0.4.0 全端 & 优化

- Web 客户端
- PC 客户端
- 语音消息
- 大群优化（读写扩散混合）
- 离线推送集成
